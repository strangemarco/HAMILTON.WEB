# Manual de Usuario - Repuestos Hamilton

¡Bienvenido al sistema de gestión de Repuestos Hamilton! Este manual le guiará paso a paso en el uso de las diferentes herramientas que el sistema ofrece para facilitar el control de su tienda.

---

## 1. Acceso al Sistema
Para ingresar al sistema, diríjase a la página principal de acceso e introduzca su **Correo Electrónico** y **Contraseña**. 

El sistema cuenta con dos niveles de acceso:
*   **Administrador:** Tiene control total. Puede ver los reportes, el historial de movimientos, gestionar inventarios y crear nuevos usuarios.
*   **Cajero:** Tiene un acceso enfocado únicamente en la venta operativa. Puede ver el inventario, realizar notas de venta y realizar el cierre de su propia caja. No tiene acceso a las configuraciones del sistema.

---

## 2. Panel Principal (Dashboard)
*(Exclusivo para Administradores)*

Al ingresar, verá el **Dashboard**, que es un resumen visual del estado de su tienda en tiempo real:
*   **Métricas del día:** Total de ventas generadas y dinero ingresado hoy.
*   **Alertas de Stock:** Un aviso rápido si tiene productos que se están agotando.
*   **Actividad Reciente:** Un vistazo a las últimas acciones que su personal ha realizado en el sistema.

---

## 3. Módulo de Inventario
Aquí es donde administra todos los repuestos de la tienda. 

*   **Búsqueda Rápida:** Use la barra superior para buscar repuestos al instante por código, nombre o sustituto.
*   **Filtros:** Puede ver solo los productos de una marca específica o separar los productos "Activos" de los dados de "Baja".
*   **Añadir o Editar Repuesto:** Al crear o modificar un producto, el sistema le pedirá el código, descripción, cantidades y hasta 3 niveles de precio (Precio de Compra, Precio Límite y Precio de Venta al Público).
*   **Dar de Baja:** Si un repuesto se daña o se pierde, puede "Dar de baja" el producto. El sistema le pedirá que ingrese un motivo (ej. "Pieza rota") para mantener el control.
*   **Exportar e Importar (Excel):** Puede descargar todo su inventario en formato Excel con un solo clic, o subir una lista masiva de productos nuevos usando la plantilla predefinida.

---

## 4. Notas de Venta (Punto de Venta)
El corazón de la tienda. Esta pantalla está diseñada para ser rápida y eficiente frente al cliente.

*   **Agregar al Carrito:** Busque el repuesto y haga clic en "+". Puede ajustar la cantidad directamente en la tabla de la derecha. El sistema calculará el Total automáticamente.
*   **Métodos de Pago:** Al momento de cobrar, puede seleccionar cómo pagó el cliente:
    *   *Efectivo:* Pago en billetes físicos.
    *   *QR / Transferencia:* Pagos digitales.
    *   *Mixto:* Si el cliente paga una parte en efectivo y otra por QR, el sistema le permitirá registrar exactamente cuánto fue por cada método.
*   **Impresión de Comprobante:** Una vez confirmada la venta, el sistema generará de inmediato un comprobante limpio (formato ticket) listo para imprimirse en su impresora térmica y entregarse al cliente.

---

## 5. Cierre de Caja
Al finalizar el turno o el día, este módulo le ayudará a cuadrar sus cuentas.

*   **Resumen Automático:** El sistema suma automáticamente todas las ventas del día en curso.
*   **Desglose:** Le mostrará exactamente cuánto dinero físico (Efectivo) debería tener en la gaveta y cuánto dinero ingresó al banco (QR).
*   **Reporte Excel:** Puede exportar el cierre de caja a Excel para guardarlo o enviárselo al contador.

---

## 6. Configuración del Sistema
*(Exclusivo para Administradores)*

### Usuarios
Permite al administrador ver la lista de todos los empleados con acceso al sistema y actualizar su información (Nombre, Carnet de Identidad) o cambiar su rol (de Cajero a Administrador).

### Historial de Movimientos (Registro de Actividad)
Es una "cámara de seguridad" digital. Todo lo que pasa en el sistema queda registrado aquí.
*   Podrá ver a qué hora exacta un cajero hizo una venta, si alguien modificó el precio de un producto, o si se importó un archivo de Excel.
*   Puede navegar entre las páginas si hay muchos registros y descargar un Excel completo con todo el historial para auditorías.
